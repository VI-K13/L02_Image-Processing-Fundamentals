# Image Processing Fundamentals - Lab 02

This repository contains my completed Lab 02 notebook for ITAI 1378: From Pixels to Perception.

The lab explores how digital images are represented as numerical matrices and how different image processing techniques affect their appearance and data.

## Topics Covered

- RGB channels and grayscale conversion
- Brightness and contrast adjustments
- Convolution filters
- Blur, sharpening, and edge detection
- Histogram analysis and equalization
- CLAHE enhancement
- Geometric transformations
- Creative image effects
- Connections between traditional image processing and AI
